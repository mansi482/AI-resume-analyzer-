# AI Resume Analyzer

## Project Overview

AI Resume Analyzer is an intelligent web application designed to help job seekers evaluate and improve their resumes based on specific job descriptions.

The application uses Artificial Intelligence to analyze resume content, identify relevant skills, evaluate compatibility with job requirements, and generate personalized recommendations for improvement.

It helps candidates understand their strengths, identify missing skills, and optimize their resumes for better alignment with job opportunities.

## Key Features

- Resume Upload and Text Extraction
- Job Description Analysis
- AI-Powered Resume Evaluation
- ATS Compatibility Scoring
- Matching and Missing Skills Identification
- AI-Generated Resume Improvement Suggestions

## Project Objective

To simplify resume evaluation through AI-powered analysis and help job seekers create more relevant, structured, and job-specific resumes.
